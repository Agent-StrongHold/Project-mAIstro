## Root cause of the coverage failure (a real defect, not just a missing test)

`read_file` checked `run.exit_code != 0` BEFORE `run.timed_out`.
`run_bounded` kills a timed-out child, whose exit status is then nonzero
(-9), so the timeout branch was unreachable and a slow container was
misreported as `FileNotFoundError` — the wrong verdict for an agent deciding
what to do next. The missing branch arcs the gate flagged WERE the defect.
