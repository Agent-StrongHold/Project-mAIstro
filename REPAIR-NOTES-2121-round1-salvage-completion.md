The previous implementation round modified `scripts/bench_gpu_rental_arbitrage.py`
and `tests/test_bench_gpu_rental_arbitrage.py` **without committing them** and
stopped mid-change. The uncommitted diff (preserved verbatim at
`/home/dev/maistro/jobs/93bbd6811d304bd8afb7d20b44e2e1d1/incoming-2121-salvage.patch`):

1. `redo_multiplier`: single-preemption `1 + 0.5·p` → geometric
   `1 + 0.5·p/(1−p)` — correct, because `_task_body` draws preemption per
   *attempt* (script line ~798: "the draw includes the attempt number") and
   `_replay_execute` retries `while not done`, so the expected number of
   preemptions before completion is the geometric mean p/(1−p).
2. `expected_accepted_task_cost`: honored `offer.min_duration_hours` at
   session level (`max(session_seconds, min_duration_hours·3600)`) before
   amortizing over `SESSION_TASKS` — the issue's required design item 1 puts
   min duration in the schema; the old model accepted the field but never
   priced it.
3. `_describe_route`: recomputes a finite expected cost for any serviceable
   pick instead of reporting null for `fixed-gpu`/`cheapest-listed`.
4. `run_replay(..., tasks_per_class)`: the failure-injection replay now
   actually receives the batch size (previously defaulted to 6 regardless of
   the CLI arg, so the recorded baseline's failure section disagreed with its
   own `tasks_per_class: 40`).
