# Authority and Agency Index

Load this index when a task involves approval, delegation, elevated actions, policy changes, agent trust, repository security posture, or human intervention.

- [Human and agent authority](human-agent-authority.md): humans retain ultimate authority; normal authorized work must not require unnecessary human keyboard labor; authenticated OBO approval is a valid human-in-the-loop mechanism.
- [Development repository threat model](development-repo-threat-model.md): this pre-1.0 repository is operated by the owner and authorized agents; optimize controls for realistic development risks while keeping product security invariants strict.

Do not infer that an agent may silently self-authorize. Do not infer that explicit owner authority becomes invalid merely because an agent executes the approved operation.
