# Example install answers

YAML in this directory is **sanitized**: no API keys, tokens, or `.env` contents.

- **`answers-v1-minimal.yaml`** — smallest valid v1 file for `maistro-install --answers-file`.
- **`answers-v1-stack.yaml`** — enables `stack_bringup: root_full` for testing `--apply` (still requires a real `.env` at repo root for compose).

Secrets and tenancy intent: [USERS-AND-AGENTS.md](../USERS-AND-AGENTS.md).
