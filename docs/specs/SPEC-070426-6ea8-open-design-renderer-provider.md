# SPEC-070426-6ea8: Open Design renderer provider

## Context

ADR-070426-f2a0 names `nexu-io/open-design` (Apache-2.0) as the first external renderer
provider — the one that fills the slots canvas cannot: `renderer.reflowable-web`,
`renderer.video`, plus `renderer.deck` (alternate path) and `designsystems.live`. We
already vendor its design-system corpus (ADR-100 / SPEC-234); this SPEC adds a **live**
provider that implements the substrate defined in SPEC-070426-a22b. Open Design runs a
local daemon, so the provider is a discoverable local integration, not a hard dependency.

## Goals

- Implement `OpenDesignProvider(RenderProvider)` filling the four slots above.
- Discover the daemon via a health probe; register nothing when it is absent (no error).
- Render a prompt stack to artifacts over the daemon's REST/SSE API and ingest them as an `ArtifactNode` tree.
- Tier outputs T2 and scan on ingest; keep the daemon behind config + a vault-held token.
- Allow Stronghold to policy-deny the provider's slots per tenant.

## Non-goals

- The provider-agnostic substrate (SPEC-070426-a22b).
- Canvas-native exporters (SPEC-070426-457b).
- Exposing Open Design's BYOK `/api/proxy/*` endpoints through maistro (we call render endpoints only).
- An automated re-sync of the vendored design-system corpus.

## Decision

### Daemon surface (as of nexu-io/open-design main)
- Base URL: `http://127.0.0.1:7456` (configurable — `--daemon-port` / `OPEN_DESIGN_PORT`).
- Auth: `Authorization: Bearer <OD_API_TOKEN>` (token generated by the operator; stored in the age vault).
- Health: `GET /api/health`.
- Render/dispatch: `POST /api/chat` (SSE). Artifacts served at `/artifacts/*`; HyperFrames at `/frames/*`.
- Metadata: `GET /api/skills`, `GET /api/design-systems`.

### Discovery
```python
async def discover(self) -> DiscoveryResult:
    if not self.cfg.enabled:
        return DiscoveryResult.down()
    try:
        r = await self._client.get(f"{self.base_url}/api/health",
                                   headers=self._auth, timeout=1.5)
        return DiscoveryResult.up(self.slots) if r.ok else DiscoveryResult.down()
    except (ConnectionError, Timeout):
        return DiscoveryResult.down()   # not installed => feature absent, silently
```

### Render
Dispatch the prompt stack to `POST /api/chat`, stream SSE to completion, collect the
written artifacts from `/artifacts/*` (or `/frames/*` for video), map them to an
`ArtifactNode` tree (ADR-062326-702b), run the existing output scan, and return a
`DesignOutput`. A daemon error trips the substrate's circuit breaker (SPEC-070426-a22b).

### Trust & posture
Outputs are third-party → `TrustTier.T2`, scanned on ingest (defense-in-depth, mirroring
the catalog-import scan in SPEC-234). The provider is a permissioned capability so
Stronghold can deny its slots per tenant; Agent Conductor discovers and enables them.

### Config
`design.plugins.open_design.{enabled, url, token_ref}` — token resolved from the vault, never inline.

## Acceptance criteria

- Daemon down/unreachable → provider registers no slots → `reflowable-web`/`video`/`deck` skills are not offered; no error surfaces.
- Daemon up → those skills are offered; a `reflowable-web` render returns a scanned `ArtifactNode` tree.
- A daemon 5xx / disconnect mid-render trips the circuit breaker and surfaces to the caller, not the pipeline.
- With the provider policy-denied (Stronghold tenant), slots stay empty even when the daemon is reachable.

## Testing

- Unit: `discover()` up/down against a mock health endpoint; config-disabled short-circuit.
- Integration: SSE render against a stubbed daemon → artifact ingest + scan.
- Security: T2 tagging + Warden scan invoked on ingested artifacts; token sourced from vault, never logged.

## Open questions

- MCP-server mode vs. REST daemon mode — support both, or REST first? (Quickstart documents REST; MCP registration is undocumented for the daemon.)
- Version pinning: which Open Design daemon versions do we certify against?
- Do we import Open Design's live `/api/skills` as additional `DesignSkill`s, or only use it as a renderer?
