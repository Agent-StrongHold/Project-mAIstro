## Legacy-archive resumability reconciliation (prior review finding)

The issue asks that pre-convergence records stay "readable/resumable". The
accepted [ADR-082826-d9f5](../../adr/ADR-082826-d9f5-durable-graph-store-as-canonical-projection.md)
(AC-6) supersedes the "resumable" half: archived Runs reproduce fully
(Run/NodeRuns/Attempts/traversal read back through the canonical models) but
`ArchivedGraphRun.resume()` refuses **by name**
(`LegacyRunNotResumable: ... can be read but not resumed`), because those
identities were never admitted to the spine and a silent re-admission would
mint a second record for one execution — the exact duplicate-authority defect
this issue retires. New execution therefore requires canonical admission; old
records remain readable evidence. Locked in by
`packages/maistro-core/tests/graph/durable_runs/test_legacy_archive.py`
(`@pytest.mark.ac("ADR-082826-d9f5/AC-6")`, 14 passing).
