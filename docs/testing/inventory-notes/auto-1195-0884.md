## What the branch adds (+7)

**`capabilities/test_invocation_store.py` +5** — the three untested exits
from `SqliteInvocationStore.claim`, the branch's atomic admission seam. It
opens `BEGIN IMMEDIATE` before reading history, so every exit owes the
database a rollback; the untested exits were the failure paths, which only
happen when two workers race. Covered: a completed prior is returned without
re-dispatch and the lock released; a non-terminal prior refused as unsafe; a
FAILED prior admitted; a lost insert race reported as `UnsafeEffectRetry`
rather than a raw `IntegrityError` (which a replaying caller would not catch);
and an unexpected escape still releasing the lock — two of these proved by a
subsequent write that would block on a stranded lock.

**`capabilities/test_invocation_layer_states_its_reach.py` +3/−1** —
`test_the_sqlite_store_is_distinct_from_event_invocations` replaced by three
narrower assertions: the store disambiguates itself from the handler store,
documents runtime schema ownership, and is wired by the effect context.

## What the split removed

Jira and Airtable polling are not M1 critical path and their migration was
split off for much later (Blake, 2026-09-29). `test_pm_polling_nodes.py` was
deleted along with the two modules it tested, and six graph-node test files
plus `runs/test_parked_run_resume.py` went back to `develop`'s versions,
which pin the pre-migration nodes that are still what ships.
