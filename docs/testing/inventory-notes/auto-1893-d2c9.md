## Why

The test accompanies an uncommitted source change found in the worktree at the
start of this round (backed up verbatim to the job directory as
`incoming-salvage-1893.patch`, sha256
`6c4f87cbfe81e1a27df9d2acf7a985162256ca46b202dd20fca6b3fe41a49c08`):
`InstallablePackRegistry.install` now rejects a pack whose id already belongs
to an active M9-B2 extension with `PackIdentityConflict`. Without the guard,
`_active_versions()` overwrites the extension's version with the pack's
(`versions[pack_id] = version`), silently retargeting every dependent during
dependency resolution. Proven meaningful, not tautological: with the guard
reversed the test fails with `DID NOT RAISE PackIdentityConflict`; with the
guard restored (byte-identical re-application) it passes.
