# m1-1162-e1

Six new tests, all additions, no removals or compensating changes — the
poison-row isolation regression suite for `SqliteEventOutbox` (#1162), appended
to `tests/events/test_outbox.py` as one class plus one legacy-upgrade test:

- `test_failing_head_does_not_block_independent_rows`: a poisoned first row
  does not stop later rows of unrelated streams.
- `test_failing_row_dead_letters_after_attempt_bound`: attempts/`last_error`
  accumulate per row; at the bound the row is dead-lettered, never retried
  again, and leaves `pending_count`.
- `test_dead_letter_releases_same_stream_followers`: per-stream FIFO holds the
  follower while the head retries, releases it at the dead letter; the
  quarantined event never occupies a stream sequence.
- `test_backoff_defers_failed_row_retry`: `next_attempt_at` gates selection
  (injected clock, no sleeps); a same-stream follower cannot leapfrog a backed
  -off head.
- `test_republish_and_unrelated_failure_never_duplicate`: redelivery and an
  unrelated row exhausting its bound never duplicate a published event.
- `test_ensure_schema_upgrades_legacy_table`: a pre-#1162-shaped table is
  upgraded in place and its legacy row's stream is backfilled from the stored
  envelope.

Verified +6 = collected 9528 vs the 9522 the ledger expected before this
change (`scripts/check-suite-inventory.py --suite packages/maistro-core/tests`);
