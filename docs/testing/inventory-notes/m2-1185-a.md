# m2-1185-a — canonical password policy at first-run setup

The Conductor backend suite gains five node IDs in
`test_setup_guard.py`: three direct HTTP requests prove empty and below-minimum
admin passwords are rejected before the setup claim or account stores change,
one verifies the exact eight-character and Unicode boundary values, and one
checks malformed setup payloads receive typed Pydantic validation errors before
provisioning. The implementation also moves the existing ordinary registration
length check into the shared `maistro.security.passwords.validate_password`
validator, so setup and registration cannot drift.
