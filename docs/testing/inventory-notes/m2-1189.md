# #1189 recovery-secret constant-time comparison

Routes the recovery-seed comparison in
`maistro.identity.lifecycle.recover_agent_identity` through the shared
constant-time comparator (`maistro.security.secret_equal`), hex-encoding the
normalized 32-byte seed deterministically before the comparison boundary. The
invalid-mnemonic error no longer interpolates the underlying bip_utils
exception (its message can embed the full mnemonic); it names only the
exception type and suppresses the cause chain, so failure diagnostics never
carry the recovery words.

Adds three lifecycle tests: a behavioral guard that forces `secret_equal` to
reject an otherwise correct recovery seed and asserts the boundary called it
with the hex-encoded normalized/stored seeds; a source guard that fails if the
module regresses to plain `!=` on the seed material or drops the
`secret_equal(` call; and a sanitization guard asserting an invalid-mnemonic
failure message (and its suppressed traceback context) never contains the
submitted words.
