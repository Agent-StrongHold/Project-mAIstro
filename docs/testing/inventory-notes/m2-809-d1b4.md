# m2-809-d1b4

`write_bootstrap_credentials` staged secrets by opening the final path with
`O_WRONLY|O_CREAT|O_TRUNC` — no `O_NOFOLLOW`, no exclusivity, no atomicity
(#809). A pre-existing 0644 file kept its permissive mode while the new
secret bytes landed in it, a planted symlink redirected the generated
passwords outside the artifacts directory, and an interruption left truncated
JSON that a later run treated as staged input.

All 16 added nodes live in `test_credentials.py`, in five classes that mirror
the issue's acceptance criteria: symlink planting refused (and the link's
target provably unwritten), a pre-existing permissive file replaced by a
fresh 0600 inode rather than re-chmodded, interruption at either end of the
atomic promotion leaving no partial file and no secret-bearing temp file,
parse-validation gating reuse of an existing staging (existence alone is not
success), and the mode-at-write-time proof — an `os.replace` interception plus
a watcher thread that samples mode and bytes through one fd, asserting secret
bytes are never observed at a mode wider than 0600. No tests were removed or
replaced; the five pre-existing nodes in the file are unchanged.
