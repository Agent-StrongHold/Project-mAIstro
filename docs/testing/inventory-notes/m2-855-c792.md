# m2-855-c792 — browser transport governed by the outbound policy

#855 moves the browser tool's destination check from the starting URL of a
session to the Playwright route layer, where every navigation, redirect hop
and subrequest is decided before the network stack connects.

The +56 node IDs are three files, not one:

- `tests/tools/browser/test_net_guard.py` (new, 41 IDs) proves the guard's
  decisions against a controlled Playwright transport: public allowed,
  every spelling of loopback/private/link-local/metadata denied, redirect
  hops into private refused at the hop, subresources and WebSocket upgrades
  governed, configured allowances exact-origin scoped, and the audit events
  origin-only (no query strings).
- `tests/tools/browser/fakes.py` (new, not collected) is that controlled
  transport — fake Route/Request/Context doubles whose `navigate` pushes a
  request through the registered handlers the way Chromium would.
- `tests/tools/browser/test_client.py` grew the wiring half (18 IDs net):
  the session handed to browser-use is guarded before the Agent sees it,
  teardown closes the Playwright objects on every path — including the
  half-built ones, where Chromium refuses to launch or the context cannot
  be created — an ungovernable browser-use build is refused rather than
  run (a `Browser` class that no longer names the context param falls
  through to a provably governed strategy instead), and a model-invented
  navigation to `127.0.0.1` during `search_web`/`browse` is denied and
  audited. The pre-existing tests were re-based onto the fakes because
  every session now launches through the guarded path. (+3 repair IDs,
  2026-09-02: the two launch-failure teardown arcs and the
  context-less-Browser fallthrough the Coverage gate named.)
